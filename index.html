Simple Notes

A lightweight Chrome extension for quick note-taking — auto-save, colour palette, and light & dark mode.

Capture quick, secure notes without ever leaving your browser. Everything is stored locally for maximum privacy.

Setup Guide

📥

From the releases page of the GitHub repository linked above, download the ZIP (.zip) file of the latest release.

📁

Extract the files into your folder of choice. This will become the location where you host the chrome extension.

⚙️

Navigate to chrome://extensions/ in the browser. You can also find this by clicking the menu button and looking for Manage Extensions.

☑️

Enable Developer mode, if you have not done this before. It is usually found in the top right corner.

🟢

Click Load unpacked and select the folder you extracted the ZIP files into in step 2. The chosen folder should contain manifest.json.

Updates

🔄️

Fetch a the new version from the Downloads above. Replace the existing files in the folder that hosts your extension. Click the reload icon on the card in chrome://extensions/.
